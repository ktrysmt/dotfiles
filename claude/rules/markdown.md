# Mermaid Diagrams

- Use a vertical (top-to-bottom) layout. Prefer tall, narrow diagrams over wide ones.
- Write all labels in Japanese.
- Use `<br>` for line breaks inside node labels.
- Keep every node definition on a single source line. Never put a literal newline inside a label.
- Use muted, low-saturation custom colors that work on dark backgrounds.

# Formatting

- Never use bold. Use headings or plain text instead.
