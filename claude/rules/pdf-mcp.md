# PDF MCP Tool Selection

- Start every PDF task with pdf-mcp: run `pdf_info` first, then `pdf_search` or `pdf_read_pages`.
- Switch to pdf-docling when pdf-mcp returns empty or garbled text, or when the task needs OCR, table structure, document editing or creation, non-PDF input, a full Markdown export, or layout analysis.
