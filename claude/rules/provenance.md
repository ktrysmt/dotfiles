# Provenance of artifacts

- Classify every existing artifact by provenance before using it: user-decided, agreed elsewhere (cite the URL), or agent-drafted. Agent-drafted artifacts carry no authority.
- Never use an agent-drafted artifact as the baseline of a comparison. Derive the target state from requirements and agreed docs first, and express the current code only as the diff to fix.
- Do not present pros and cons when one side has no rationale. State the target state.
- Before presenting a structural change, read the affected files and check names, references and uniqueness under the new structure.
- Never embed an unverified assumption in the options of a question. Check the agreed source first.
